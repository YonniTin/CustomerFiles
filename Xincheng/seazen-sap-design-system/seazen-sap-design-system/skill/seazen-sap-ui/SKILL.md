# 绿洲 SAP UI

为绿洲商管 SAPUI5 桌面系统产出可追溯的界面与验收证据。当前版本 0.9.1-review 是评审稿，不能把候选清单或补充建议说成已批准制度。用户明确的任务范围和授权保持不变。

## 使用资料

- 先读取 [设计规范](references/design-guidelines.md) 的核心摘要、与本次页面相关的组件/模式和冲突清单。
- 读取 [Token](references/tokens.json) 及 [业务策略](references/business-rules.json)。它们携带来源和暂定状态，英文状态键是演示别名。
- 产品需求缺少组织/权限/字段/审批策略时，使用 [任务模板](references/ai-task-template.md) 整理缺口。继续完成不依赖缺口的工作；不编造业务权限。
- 生成后按 [验收清单](references/checklist.md) 检查，输出截图/交互证据、偏离和待确认项。

## 必须保留的项目特征

- S1 文档记录为 UI5 1.71.70、sap_fiori_3、sapUiSizeCompact、根字号 12px。本次 U1 已确认所有可见文字最小 12px；正文、辅助、标签、按钮 12px，业务标题 14px / 400，主按钮文字 700。D01 已关闭，旧的小字号不能重新启用。
- 原生 UI5 不能仅设置根字号后保留默认 rem 字号；应覆盖相关主题/控件字号，并验证最终计算字号至少 12px。
- 品牌蓝 #427EC0，已审批也使用品牌蓝；不要套用 Ant Design 默认外观。
- 通用间距 3/6/12/24/36px；业务控件可见高 24px、占位 30px；表头 33px、数据行 30px。字号与这些关联尺寸为 U1 本次适配，不能回退成旧的小字号。
- 列表检索最多五项一行，表单最多三列；工具栏左对象(数量)、右透明文字操作；同一区域最多一个主按钮。
- 表头居中，长文本左、短文本/日期中、数值右。日期 yyyy/MM/dd，金额千分位两位小数，整数无小数，空值不补 0。
- 只读保留灰底输入框。成功/信息与错误用弹窗，不改成 Toast。
- 操作权限和单据状态使用 references/business-rules.json：未提交才可逻辑删除，修改仅三种规定状态；前置条件不足置灰，权限控制可隐藏。提交策略未确认时默认禁用。
- 商机的组织范围例外、批量策略、开关/抽屉、附加状态参数都在待确认清单，不能推广为已批准的全局规则。

## 实现与评审

HTML 原型可使用 assets/tokens.css、assets/controls.css 和 assets/business-rules.js；这些是本次交付新增的可复用演示层。生产 UI5 页面优先复用真实项目控件，并由前端核验对应版本 API；不要为套用演示而重写运行时或绕过服务端权限。

只生成任务所需结构和业务逻辑。所有原型使用虚构数据，生成页面本身不意味着获准保存、审批或导出真实单据。不要为本 Skill 增加额外发布/审批流程。

交付中写明版本、引用规则、页面模板、状态覆盖、验证结果和待确认项。规则变化时同步更新对应 Token、示例与验收项；不静默修改基线。
