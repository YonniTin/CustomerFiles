## 附加给 AI 的约束

读取同目录 design-guidelines.md、tokens.json、business-rules.json、checklist.md；如环境支持，使用 seazen-sap-ui Skill。

按绿洲 SAP UI 0.9.1-review 生成页面。业务外观沿用 SAPUI5 Compact，而不是 Ant Design 默认视觉。先选页面模板，再组合标准组件。采用可追溯 Token，严格遵守状态、权限、软删和反馈规则。

未提供的提交审批状态默认不放行；原始视觉基线 MD 未获得前保留该核对项。所有暂定值和补充建议必须标注。不能从单个旧页面或错误信息推导新的全局制度。

输出页面/代码、规则 ID 对照、目标视口截图、正常/只读/禁用/加载/空/异常状态、交互验证结果、偏离与待确认项。所有原型数据使用虚构内容，真实保存/提交/导出必须接入正式授权与服务端校验。
